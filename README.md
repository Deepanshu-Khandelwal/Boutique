# Boutique Measurement App

A premium, offline-first Flutter application designed for boutique owners and tailors to manage customer records, garment measurements, orders, and financials with ease. Built with luxury dark and light themes, local notifications, WhatsApp integration, and local backup/restore capabilities.

---

## 🌟 Key Features

- **📋 Client Management**: Maintain a detailed list of customers, including contact information and measurement histories.
- **📏 Custom Measurements**: Record precise measurements categorized by garment types (e.g., shirts, trousers, suits) with customizable measurement templates.
- **💰 Financial Tracking**: Manage order pricing, payments, and outstanding balances. All currency formatting is locked to Indian Rupees (`₹`).
- **🔔 Local Reminders**: Automatically schedule delivery reminders using `flutter_local_notifications` to ensure orders are completed on time.
- **💬 WhatsApp Integration**: Send welcome messages, delivery confirmations, or order updates directly to customers via WhatsApp.
- **💾 Local Backup & Restore**: Export client databases as encrypted JSON backups, or import existing files to restore all data.
- **🌓 Luxury Themes**: Offers a curated Light Mode (Soft Ivory/Slate) and Dark Mode (Luxury Charcoal/Champagne Gold) for a premium user experience.
- **⚡ Offline-First**: Uses Hive local database for immediate loading speeds and fully offline operation.

---

## 🛠️ Technology Stack

- **Framework**: [Flutter](https://flutter.dev) (Channel Stable)
- **State Management**: [Provider](https://pub.dev/packages/provider)
- **Local Storage**: [Hive](https://pub.dev/packages/hive) & [Hive Flutter](https://pub.dev/packages/hive_flutter)
- **Scheduling & Notifications**: [Flutter Local Notifications](https://pub.dev/packages/flutter_local_notifications) & [Timezone](https://pub.dev/packages/timezone)
- **Utilities**:
  - `share_plus` (Database Exporting)
  - `file_picker` (Database Importing)
  - `url_launcher` (WhatsApp Integration)
  - `pdf` & `printing` (Invoice Generation)

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.44.2 or later recommended)
- Android Studio / VS Code with Dart & Flutter extensions installed.

### Setup Instructions

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd boutique
   ```

2. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

3. **Generate Hive Adapters**:
   The app uses type adapters generated by `build_runner` for local database serialization. Run the code generator:
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```

4. **Run the Application**:
   - For Android/iOS devices/emulators:
     ```bash
     flutter run
     ```
   - For web (Chrome):
     ```bash
     flutter run -d chrome
     ```

## 📦 Production Release Build

To build a release version of the application for production:

### Android APK Build
The project utilizes Built-in Kotlin (Gradle Plugin v8.11+ and Kotlin compiler v2.2.20) for optimal compatibility and build speed.

To compile a release APK, run:
```bash
flutter build apk
```

The output APK file will be generated at:
`build/app/outputs/flutter-apk/app-release.apk`
